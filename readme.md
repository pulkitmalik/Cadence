# Cadence — Habit & Goal Tracker

A calm, privacy-first web app for tracking daily habits, weekly/monthly goals, focus sessions, and progress trends right in your browser.

## Features

- **Mixed Habit Tracking:** Log simple daily checkboxes (morning routine, wind-down) alongside numeric targets (sleep hours, study hours, exercise minutes, meals) with optional daily notes.
- **Custom & Archived Habits:** Add, edit, or archive habits anytime without losing past history.
- **Weekly & Monthly Goals:** Set milestone goals (e.g., subject chapters, weight or fitness targets) with days-remaining counters and daily `+`/`-` progress updates.
- **Built-in Focus Timer:** Run a Pomodoro or custom countdown directly from any habit card and auto-log elapsed time when finished.
- **Streak Protection (Rest Days):** Mark planned rest or sick days so taking a break does not break your streaks.
- **Visualizations & Reviews:** Track daily completion rings, streaks, a weekly/monthly calendar grid, interactive trend charts, and an automatic 7-day Weekly Review card.
- **Reminders & Sound Chimes:** Optional in-browser daily check-in reminders and gentle Web Audio completion chimes.
- **Light & Dark Mode:** Switch between a minimalist light theme and a dark dashboard.
- **Non-Destructive Multi-Profile Sharing:** Export your data as `.json` or `.csv`. Opening someone else's backup file adds it as a separate profile without erasing your own data, and **View Both** lets you compare two profiles side by side.

## Privacy & Storage

All habits, goals, and daily logs are stored locally in your browser's `localStorage`. No account, backend server, or external database is used.

## Getting Started

1. Open the live site (or open `index.html` in any modern browser).
2. Check off today's habits, add custom habits or weekly/monthly goals, and use **Export** to save a `.json` or `.csv` backup anytime.
